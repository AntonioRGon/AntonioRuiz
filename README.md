## 🚀 Proyectos destacados

### [Rockstar Burger](https://github.com/AntonioRuiz/rockstar-burger) *(Flutter + IA)*
App móvil de pedidos para restaurante con asistente conversacional **"Kurt"** impulsado por IA.
- 🤖 Arquitectura **RAG**: embeddings semánticos (Hugging Face) + búsqueda vectorial (ObjectBox HNSW) + generación con **Gemini**
- 🛒 Carrito de compras, checkout con **GPS** y propina configurable
- 🔐 Panel de administración del bot desde la app
- ☁️ Firebase Storage para imágenes, variables de entorno seguras

**Tecnologías:** Flutter · Dart · Gemini API · Hugging Face · ObjectBox · Firebase · Geolocator

---

### [Nexo Tech](https://github.com/AntonioRuiz/nexo-tech) *(Django + PostgreSQL)*
Marketplace de componentes de PC con backend REST y frontend responsivo.
- 🔐 Autenticación **JWT**
- 🛒 Carrito de compras, checkout y pedidos con **UUID de rastreo**
- 🔧 Configurador de PC con **validación de compatibilidad** CPU/RAM/socket en tiempo real
- 📦 API REST completa con Django REST Framework

**Tecnologías:** Python · Django · DRF · PostgreSQL · Tailwind CSS · JavaScript
